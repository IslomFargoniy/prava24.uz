# Prava24 — Haydovchilik Imtihoniga Tayyorgarlik Platformasi

![Prava24 Logo](logo.jpg)

**Prava24** — O'zbekistondagi haydovchilikka nomzodlar uchun eng zamonaviy va bepul onlayn test platformasining landing sahifasi. Loyiha foydalanuvchilarni Telegram bot orqali YHQ testlarini yechishga yo'naltiradi.

## 🚀 Loyiha haqida

Ushbu landing sahifa Prava24 platformasining asosiy imkoniyatlarini tanishtiradi:
- **2026 Yangilangan Savollar:** IIV (GAI) tomonidan tasdiqlangan eng so'nggi testlar.
- **Tezkor Tahlil:** Xatolar ustida ishlash imkoniyati.
- **Mobil Qulaylik:** Telegram bot orqali istalgan joyda test yechish.

## 🛠 Texnologiyalar

- **HTML5 & CSS3**
- **TailwindCSS** (CDN orqali)
- **Font Awesome** (Ikonkalar uchun)
- **JavaScript** (Interaktivlik uchun)

## 📈 SEO Optimallashtirish

Loyiha qidiruv tizimlarida (Google, Yandex) yuqori o'rinlarda ko'rinishi uchun quyidagi ishlar amalga oshirildi:

- **Ko'p tilli Meta teglari:** O'zbek, Rus va Ingliz tillarida kalit so'zlar.
- **JSON-LD Structured Data:** Qidiruv botlari uchun sahifa strukturasini tushuntiruvchi skript.
- **Sitemap & Robots:** `sitemap.xml` va `robots.txt` fayllari orqali indekslash yaxshilandi.
- **Open Graph:** Ijtimoiy tarmoqlarda (Telegram, Facebook) chiroyli ko'rinish uchun meta teglar.

## 📂 Fayl strukturasi

```text
.
├── index.html       # Asosiy sahifa (SEO optimallashtirilgan)
├── robots.txt       # Qidiruv botlari uchun ko'rsatmalar
├── sitemap.xml      # Sayt xaritasi
├── logo.jpg         # Platforma logotipi
└── bot_about.jpg    # Bot haqida ma'lumot beruvchi rasm
```
